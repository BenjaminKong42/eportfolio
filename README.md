# Projet eportfolio - BUT RT - 1ere année - BKONG
## Definitions du cahier des charges

J'avais comme consignes de créer un eportfolio en utilisant symfony.
Le eportfolio devait contenir des catégories des menus suivants:
- Présentation personnelle
- Mon parcours
- Pouvoir entrer en contact rapidemment
- Mon CV
  
## Developpement / code
Je me suis fortement inspiré d'un dépot git existant.
Je me suis fait aider par l'ia (chat gpt).
J'ai aussi regardé le tutorial suivant : https://symfonycasts.com/screencast/symfony/setup

# Installation
J'ai suivi l'installation déposé sur le site de symfony.
J'ai dû installer aussi les élements suivants:
- installation php
- installation composer (package php)

# Lancement (dev)

```
git clone nom du dépot
cd mon_dépot 
cd public
symfony server:start
```
# Améliorations/simplification
L'installation pourrait être réalisée avec Docker.
Cela permet d'avoir toutes les dépendances requises.

L'utilisation de symfony pourrait être remplacé par un simple code html et css.
